# Generate Handout — Раздаточный материал

## Процедура

1. Загрузи модуль/лекцию (`$ARGUMENTS`)
2. Извлеки: ключевые концепции, определения, шаги
3. Создай handout — максимум одна страница A4:

```
РЕЗЮМЕ (1 параграф): о чём это
КЛЮЧЕВЫЕ ТЕЗИСЫ (5–7 пунктов): без воды
ЧЕКЛИСТ / ПОШАГОВАЯ ИНСТРУКЦИЯ: конкретные действия
ВОПРОСЫ ДЛЯ РЕФЛЕКСИИ (3–5): открытые, не риторические
ДОПОЛНИТЕЛЬНЫЕ РЕСУРСЫ: только самые важные
```

## Правила

- Максимально сканируемый формат
- Минимум текста, максимум смысла
- Одна A4 — жёсткое ограничение
- Никаких вводных абзацев и резюме-резюме

## Результат

`handout.md` в папке модуля или `Content/`
