# Принципы письма BooksFactory

## Глубина vs. Раздувание

### Правило

Текст расширяется только через новую информацию, не через переформулировку уже сказанного.

### Методы расширения через глубину

| Метод | Описание |
|-------|---------|
| Микроанатомия | Разбить тезис на конкретные проявления — не «механизм работает», а как именно, в каких ситуациях, с какими вариациями |
| Парадокс | Каждый механизм содержит внутренний парадокс — найти и развернуть в полный абзац |
| Физиология | Телесное проявление идеи — что происходит в теле, в поведении, в речи |
| Контраргумент-и-разбор | Назвать возражение честно, признать долю правды, показать почему это не отменяет тезис |
| Арена | Конкретная сцена, разворачивающая механизм в реальном контексте (если предусмотрена tonal_compass.md) |

### Запрещённые методы расширения

| Запрещено | Почему |
|-----------|--------|
| Переформулировка тезиса другими словами | Нулевой информационный прирост |
| «Итак, мы увидели, что...» | Резюме внутри главы — AI-маркер и раздувание |
| Добавление прилагательных к существующим утверждениям | Декорация, не глубина |
| Вводные абзацы «в этой секции мы рассмотрим» | Gate 0 запрет |

## LP — Лексическое разнообразие

### Правило (из практики ОНМ, применимо ко всем книгам серии)

| Тип слова | Лимит на главу | Действие при превышении |
|-----------|---------------|------------------------|
| Нейтральные слова (человек, тело, слово, вечер) | Без ограничений | — |
| Стержневые термины главы (если ритмически оправданы) | До 4–5 раз | Только при намеренном рефрене |
| Специфические/образные слова | **Максимум 2** | Ротация |

### Стратегия ротации при 3+ повторениях

1. **Не искать одно слово-замену для всех вхождений** — это повтор под другим именем
2. Для каждого лишнего вхождения — **своё слово по локальному контексту**
3. 1–2 вхождения убрать через местоимение (каждый/каждое без существительного)
4. Одно вхождение — callback к уже звучавшему образу

### Исключение: намеренный рефрен

Повтор как ритмический приём — сохранить. Тест: «Если убрать повтор — пропадёт ритмический эффект?» Да → рефрен. Нет → дубль, заменить.

### «Паттерн» — отдельное правило

Лимит: **максимум 2 на главу** (BooksFactory default).

Ротационный список замен:
- механизм
- реакция
- привычка
- рефлекс
- схема
- контур
- способ
- маршрут
- сценарий

Правило ротации: не подбирать одно слово-замену на всю книгу — чередовать.

## Ритм

### Принцип

Монотонный ритм — главный структурный AI-маркер. Ритм — инструмент смысла, не украшение.

### Практические правила

- Чередовать короткое и длинное предложение
- Допускать неполные предложения как ритмический удар
- Не выравнивать абзацы по длине
- После длинного аналитического блока — короткий удар (1–2 предложения)
- Ритмическая пауза перед важным тезисом работает лучше, чем жирный шрифт

### Запрещённые ритмические паттерны

| Паттерн | Почему |
|---------|--------|
| 5+ абзацев одинаковой длины подряд | AI-монотонность |
| Каждый абзац начинается с коннектора (Кроме того / Также / При этом) | AI-механическая связка |
| Каждый третий абзац — список | Структурный AI-паттерн |

## Формульные конструкции — лимиты

Ритмические фигуры эффективны при дозированном применении. При злоупотреблении — превращаются в тик.

| Конструкция | Лимит на главу | При превышении |
|-------------|---------------|----------------|
| «не потому что X — а потому что Y» | T5 из Session (default ≤ 8) | Оставить ударные, проходные переписать: начать с сути без зачина |
| «и вот что делает / и вот парадокс / и вот деталь» | 1 суммарно | Оставить сильнейший, остальные: начать с существа дела |
| «паттерн» | 2 | Ротация из списка выше |
| Горькая усмешка | 1 на главу, уникальная по книге | Удалить повтор |
