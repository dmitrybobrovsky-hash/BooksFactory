# Раздел 1. Обзор проекта

## 1.1 Описание продукта

Колода «Бестиарий офисных существ» — набор метафорических ассоциативных карт (МАК) для работы с психологическими и культурными феноменами современных организаций. Колода объединяет организационную психологию, сатиру и визуальную метафору в стиле аллегорического корпоративного стимпанка.

Данная версия — русскоязычная адаптация проекта «Bestiarium der Bürowesen». Все названия карт, методическое пособие и каталог выпускаются на русском языке.

## 1.2 Целевое применение

- Психологическое консультирование и коучинг
- Анализ организационной культуры и ролей сотрудников
- Работа с профессиональным выгоранием и токсичными процессами
- Обучение организационной психологии
- Групповая рефлексия и тренинги

## 1.3 Языки

**Карты:** русский (названия на картах)

**Пособие для фасилитатора:** русский

**Промпты для генерации:** английский (требование fal.ai FLUX)

## 2.3 Решение проблемы дублей

Две карты повторяются между категориями: Тревога/Страх (состояние Z04 и сила K03) и Преданность/Лояльность (состояние Z06 и сила K10). Решение: сохранить обе карты, но дифференцировать визуально и композиционно:

| **Карта**               | **Состояние (Z)**                                   | **Сила (K)**                                  |
| ----------------------- | --------------------------------------------------- | --------------------------------------------- |
| Тревога / Страх         | Человек в центре, субъективный опыт, туманная рамка | Безличный механизм давления, цепная рамка     |
| Преданность / Лояльность| Личное чувство преданности, туманная рамка          | Системное требование лояльности, цепная рамка |

## 4.2 Стилистические принципы

**Основной стиль:** аллегорический корпоративный стимпанк

- Полуреалистичная иллюстрация с сюрреалистическими метафорами
- Тёмная академическая атмосфера (Dark Academia)
- Латунные механические элементы, драматическое освещение
- Тонкая ирония, НЕ карикатура

## 4.3 Система визуальной навигации по категориям

Каждая категория имеет уникальный визуальный маркер — стиль рамки и доминирующий мотив. Это описывается в промпте для каждой карты.

| **Категория**    | **Рамка**                  | **Доминирующий мотив** | **Композиция**                              |
| ---------------- | -------------------------- | ---------------------- | ------------------------------------------- |
| Архетипы         | Латунная орнаментальная    | Персонаж + атрибут     | Центральная фигура с символическим объектом |
| Ситуации         | Шестерёнчатая механическая | Сцена + участники      | Многофигурная композиция                    |
| Состояния        | Дымчатая / туманная        | Тело + среда           | Одна фигура во взаимодействии со средой     |
| Системные силы   | Цепная / индустриальная    | Механизм + масштаб     | Масштабные структуры с мелкими фигурами     |
| Ресурсы          | Световая / сияющая         | Свет + движение        | Фигура в динамике, светлые акценты          |

## 4.4 Элементы карты

Каждая карта содержит следующие элементы:

- Иллюстрация — занимает ~85% площади карты
- Название карты — внизу, на русском языке, в зоне safe area
- Код категории — верхний угол (A/S/Z/K/R + номер)
- Рамка категории — стиль согласно таблице 4.3

**ВАЖНО: Название и код накладываются на иллюстрацию программно (Python/Pillow), а не генерируются в FLUX. Это гарантирует читаемость и единообразие.**

**ВАЖНО: Для русского текста на карте необходимо использовать шрифт с поддержкой кириллицы (например, PT Serif, Merriweather, IBM Plex Serif). Проверить рендеринг кириллицы до массовой генерации.**

# Раздел 5. Промпт-архитектура

## 5.1 Стандартная структура промпта

Каждый промпт следует структуре из 6 блоков:

- [1] Центральный персонаж/сцена + конкретное действие
- [2] Визуальные атрибуты и символы
- [3] Окружение и среда
- [4] Стилевой блок (style baseline)
- [5] Маркер категории (тип рамки)
- [6] Композиционные указания

## 5.2 Style Baseline (единый для всех карт)

## 5.4 Правила промптов

- КАЖДЫЙ промпт должен содержать центральную человеческую фигуру (критично для проективности)
- Абстрактные карты (силы, состояния) требуют БОЛЬШЕЙ детализации, а не меньшей
- Запрещено: текст на изображении (всегда добавлять «no text on image»)
- Избегать повторения одних и тех же визуальных решений (разнообразие метафор)
- Для единообразия: использовать один seed для тестирования, затем варьировать
- Промпты пишутся на английском языке (требование FLUX)

# Раздел 6. Пайплайн генерации изображений

## 6.1 Этапы работы

- Этап 1: Подготовка промптов — Claude перерабатывает все 80 исходных промптов + пишет 7 новых (R06–R12) по стандарту раздела 5
- Этап 2: Тестовая генерация — 5 карт (по 1 из каждой категории) через fal.ai API для согласования стиля
- Этап 3: Утверждение — заказчик оценивает тестовые карты, даёт обратную связь
- Этап 4: Массовая генерация — 87 карт × 3 варианта = 261 изображение
- Этап 5: Отбор — выбор лучшего варианта для каждой карты
- Этап 6: Пост-обработка — наложение рамки, русского названия, кода категории (Python/Pillow)
- Этап 7: Сборка — финальные PNG + обзорный PDF-каталог
- Этап 8: Верификация — проверка корректного отображения кириллицы на всех 87 картах

## 6.2 Технический стек

| **Компонент**         | **Технология**                  | **Назначение**                           |
| --------------------- | ------------------------------- | ---------------------------------------- |
| Генерация иллюстраций | fal.ai FLUX.2 [pro] / [dev]    | Генерация 87 иллюстраций                |
| Пост-обработка        | Python + Pillow                 | Наложение рамок, русского текста, кодов  |
| Промпт-инжениринг     | Claude (Anthropic)              | Переработка промптов                     |

## 6.3 API-конфигурация fal.ai

Параметры вызова API:

_model: fal-ai/flux-2-pro (production) или fal-ai/flux/dev (iteration)_

_image_size: { width: 832, height: 1424 }_

_output_format: png_

_enable_safety_checker: false_

_num_images: 3 (для вариантов)_

_seed: фиксированный для тестов, рандомный для продакшна_

# Раздел 7. Пост-обработка (overlay-скрипт)

Python-скрипт накладывает на сгенерированную иллюстрацию:

- Рамку категории (латунная / шестерёнчатая / дымчатая / цепная / световая)
- Название карты внизу на русском языке (шрифт: серифный кириллический, цвет #C59A3D на тёмном фоне)
- Код категории в верхнем левом углу (A01, S12, Z04, K07, R11)
- Скругление углов R3.5 mm (опционально, для цифрового превью)

Вход: PNG 832×1424 от fal.ai + JSON с метаданными (код, название на русском, категория)

Выход: PNG 832×1424 с оверлеем

**Примечание по шрифтам:** Для кириллического текста рекомендуются: PT Serif (Google Fonts, свободная лицензия), Merriweather или IBM Plex Serif. Шрифт должен поддерживать полный набор кириллических символов и хорошо читаться на тёмном фоне при малом размере.
