# Словарь замен: лексические маркеры ИИ в русском языке

Этот документ — таблица замен. Каждая запись содержит маркер, уровень, замену и пояснение.
При работе с текстом сверяйся с этой таблицей. Не применяй замены механически — перестраивай
предложение целиком.

## Tier 1 — Безусловные маркеры {#tier-1}

Эти слова и конструкции ВСЕГДА указывают на машинную генерацию в русском тексте.
Заменяй при каждом обнаружении.

| Маркер | Замена | Почему маркер |
|--------|--------|---------------|
| Важно отметить, что... | Убери вводную, начни с сути | Топ-1 маркер ChatGPT на русском |
| Стоит отметить, что... | Убери вводную | Вариант предыдущего |
| Следует отметить, что... | Убери вводную | Вариант предыдущего |
| Необходимо подчеркнуть | Убери, скажи прямо | Канцелярский маркер ИИ |
| Нельзя не упомянуть | Убери, просто упомяни | Ложная скромность ИИ |
| В современном мире... | Убери целиком или назови конкретный контекст | Пустой зачин |
| В мире, где... | Убери целиком | Англицизм-калька «In a world where» |
| В эпоху [чего-либо]... | Назови конкретное время/событие | Ложная масштабность |
| Подводя итог... | Убери, итог должен быть очевиден из текста | Шаблонное завершение |
| В заключение можно сказать... | Убери целиком | Школьное сочинение |
| Таким образом, мы приходим к выводу... | Убери или перефразируй конкретно | Дипломная работа |
| Конечно! / Разумеется! (в начале ответа) | Убери | Артефакт чат-бота |
| Надеюсь, это было полезно | Убери целиком | Артефакт чат-бота |
| Если у вас остались вопросы... | Убери целиком | Артефакт чат-бота |
| Давайте рассмотрим... | Начни рассматривать без объявления | Метакомментарий |
| Давайте разберёмся... | Начни разбираться без объявления | Метакомментарий |
| Давайте погрузимся в... | Калька «Let's dive into» | Англицизм |
| Не будет преувеличением сказать | Скажи прямо — если не преувеличение, зачем оговорка? | Хеджирование ИИ |

## Tier 2 — Маркеры при кластеризации {#tier-2}

Одно вхождение допустимо. Два и более в пределах 500 слов — заменяй.

| Маркер | Замена | Контекст |
|--------|--------|----------|
| играет [важную/ключевую/значительную] роль | назови конкретное действие | «X играет ключевую роль» → «X определяет/влияет/задаёт» |
| является [основой/фундаментом/ключом] | перестрой: «лежит в основе» или назови связь | Калька «is the foundation» |
| представляет собой | замени на «это» или перестрой | Канцелярит |
| оказывает [значительное] влияние | назови, как именно влияет | Абстракция вместо конкретики |
| способствует [развитию/улучшению] | назови механизм | Размытость |
| обеспечивает [возможность/основу] | назови, что конкретно даёт | Канцелярит |
| имеет [большое/огромное] значение | скажи, для чего и почему | Пустая оценка |
| на сегодняшний день | «сейчас» или убери | Канцелярное раздувание |
| в настоящее время | «сейчас» или убери | Канцелярное раздувание |
| в рамках [данной статьи/исследования] | убери или назови конкретно | Метакомментарий |
| данный [факт/аспект/вопрос] | «этот» или убери указатель | Канцелярит, «данный» = маркер |
| вышеупомянутый / нижеследующий | «этот», «такой» или убери | Бюрократический стиль |
| безусловно | убери или замени на конкретный аргумент | Ложная убедительность |
| несомненно | убери или замени на конкретный аргумент | Ложная убедительность |
| ключевой аспект | назови аспект без «ключевой» | Инфляция значимости |
| неотъемлемая часть | часто можно просто «часть» | Инфляция значимости |
| широкий спектр | назови конкретные примеры | Размытость |
| целый ряд | назови, сколько или какие | Размытость |
| комплексный подход | опиши, что включает | Пустой термин |
| эффективный инструмент | назови, в чём эффективность | Пустая оценка |

## Tier 3 — Маркеры при высокой плотности {#tier-3}

Нормальны в малых дозах. Флагуй при плотности > 3 на 1000 слов.

| Маркер | Когда проблема | Замена |
|--------|---------------|--------|
| однако | > 2 на 1000 слов | «но», «хотя», перестрой без противопоставления |
| кроме того | > 2 на 1000 слов | «ещё», «а ещё», «плюс к этому» или убери |
| более того | > 1 на 1000 слов | перестрой: усиль мысль без маркера |
| помимо этого | > 2 на 1000 слов | «ещё» или убери |
| тем не менее | > 1 на 1000 слов | «но», «и всё же» |
| вместе с тем | > 1 на 1000 слов | «при этом», «но» |
| в свою очередь | > 1 на 1000 слов | убери, связь должна быть очевидна |
| соответственно | > 1 на 1000 слов | убери, логика должна быть понятна |
| следовательно | > 2 на 1000 слов | «значит», «поэтому» |
| таким образом | > 1 на 1000 слов (кроме финала) | «так что», «итого» или убери |
| при этом | > 3 на 1000 слов | перестрой предложение |
| в то же время | > 1 на 1000 слов | «одновременно» или убери |
| с другой стороны | > 1 на 1000 слов | «но» или перестрой |

## Вводные конструкции и связки {#вводные}

ИИ злоупотребляет вводными конструкциями. Правило: если вводная не несёт информации — убери.

| Шаблон ИИ | Что делать |
|-----------|------------|
| Как мы уже упоминали ранее... | Убери. Если упоминал — читатель помнит |
| Как известно... | Если известно — зачем говорить? Убери |
| Не секрет, что... | Убери. Начни с факта |
| Очевидно, что... | Если очевидно — не нужно объявлять. Убери |
| Интересно, что... | Покажи, почему интересно, через подачу факта |
| Примечательно, что... | Аналогично |
| Хочется отметить, что... | Отметь без объявления |
| Не стоит забывать о том, что... | Просто скажи |

## Заключительные штампы {#заключительные}

| Штамп | Замена |
|-------|--------|
| Подводя итог, можно сказать, что... | Убери вводную. Итог = последнее предложение |
| В заключение хотелось бы отметить... | Убери. Скажи то, что хотел |
| Таким образом, [X] является важной темой | Убери. Если текст хороший — это и так ясно |
| Остаётся надеяться, что... | Скажи, что конкретно нужно сделать |
| Время покажет... | Назови конкретные развилки или убери |
| Только будущее покажет... | Калька «Only time will tell». Убери |
| Эта тема заслуживает дальнейшего изучения | Назови, какие вопросы открыты |
| Данная проблема требует комплексного подхода | Назови, какие именно шаги нужны |

## Глаголы-пустышки {#глаголы-пустышки}

ИИ избегает прямых глаголов и заменяет их на конструкции «глагол + абстрактное существительное».

| Конструкция ИИ | Прямая замена |
|----------------|-------------- |
| осуществлять контроль | контролировать |
| производить оценку | оценивать |
| оказывать влияние | влиять |
| принимать решение | решать |
| вносить вклад | помогать / участвовать / [конкретика] |
| предпринимать попытки | пытаться |
| проводить анализ | анализировать |
| обеспечивать функционирование | обеспечивать работу / чтобы [X] работал |
| осуществлять деятельность | работать / делать |
| являться причиной | вызывать / приводить к |
| оказывать содействие | помогать |
| находить применение | применяться / использоваться |
| получить распространение | распространиться |
| носить характер | быть [каким] |

## Правила применения {#правила}

1. **Не заменяй механически.** Каждая замена — это перестройка предложения.
   Синонимическая подстановка создаёт новые маркеры.

2. **Проверяй кластеры.** Одно «однако» — нормально. Три «однако» на страницу — маркер.
   Считай вхождения Tier 2 и Tier 3 в скользящем окне 500 слов.

3. **Приоритет уровней.** Сначала Tier 1 (убрать все). Затем Tier 2 (убрать кластеры).
   Затем Tier 3 (проверить плотность). Это порядок прохода по тексту.

4. **Контекст важнее правила.** В научной статье «представляет собой» может быть уместно.
   В блог-посте — нет. Учитывай жанр.

5. **Не создавай новые маркеры при замене.** Если убрал «Важно отметить» — не ставь
   «Стоит подчеркнуть». Перестрой предложение так, чтобы факт шёл первым.
