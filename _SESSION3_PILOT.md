# Сессия 3 — пробный прогон (KS, глава 02)

Работай только в директории BooksFactory и папке книги `_outbound/Test3_05.05.2026`.
**Вопросов автору не задавай.** Останавливайся только если шаг невозможен без его решения; всё остальное — в отчёт.
Глава 01 не трогается (остаётся майским образцом).

## A. Проверка программы

1. Выполни `/workflow-authoring` и сверь `.claude/workflows/write-chapter.js` с правилами скилла.
2. Если есть несоответствия API (имена функций, формат meta, schema, запреты) — исправь **только их**, ничего больше. Каждое исправление запиши в отчёт: было → стало.
3. `python tools/validate_factory.py` — ожидается «ЧИСТО».

## B. Beat-план главы 02

1. Запусти агента `bf-planner` для главы 02 книги KS: вход `MATERIAL_Glava_02_KS.md` и бриф книги в папке книги, выход `02_beat_plan.json`. Длинный MATERIAL читать частями.
2. Проверь, что `02_beat_plan.json` — валидный JSON с полями `chapter_number`, `chapter_target_words`, `beats` (у каждого beat: `beat_id`, `section`, `thema`, `target_words`).

## C. Написание главы

Запусти `/write-chapter` с данными:
`{ book_dir: "_outbound/Test3_05.05.2026", code: "KS", chapter: "02", lang: "ru", word_limits: ["паттерн=2"] }`

Дождись окончания. Если workflow остановился (`stopped` / `needs_author`) — не перезапускай, зафиксируй в отчёте, на каком beat-е и почему.

## D. Редактура

Если глава собрана (статус `draft`):
1. Запусти `bf-editor` по `Glava_02_KS_draft.md` — отчёт редактора в папку книги.
2. `python tools/manifest.py set --book-dir _outbound/Test3_05.05.2026 --chapter 02 --status review --by bf-editor`

Дальше не идти: правки по отчёту редактора — решение автора.

## E. Отчёт

Запиши `_SESSION3_PILOT_REPORT.md`:
- A: найденные несоответствия и исправления;
- B: число beat-ов, сумма целевых слов, цель главы;
- C: итог workflow; по каждому beat-у — слова, итерации, принят ли; общее время; расход токенов, если виден в `/workflows`;
- D: главные пункты отчёта редактора (кратко);
- всё необычное, что заметил.
