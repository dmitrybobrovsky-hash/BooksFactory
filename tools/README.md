# tools/ — детерминированный слой BooksFactory

Всё, что можно посчитать или проверить без модели, делают эти скрипты. Модели пишут и судят.
Только стандартная библиотека Python 3.10+.

| Скрипт | Что делает | Кто вызывает |
|---|---|---|
| `validate_factory.py` | Чистота фабрики: нет следов конкретных книг; агенты и скиллы оформлены правильно | после любой правки фабрики |
| `manifest.py` | Статусы глав книги (`book_manifest.json`) — единственный писатель; запрещает перескакивать этапы, `final` ставит только автор | все роли при смене статуса |
| `zotero_pool.py` | Подборка автора из Zotero (CSL JSON) → заготовка списка литературы | bf-researcher |
| `verify_sources.py` | Сверка списка литературы по каталогам (Open Library, Google Books): автор, год, ISBN | bf-researcher перед GATE-2 |
| `slice_context.py` | Пакет контекста для одного beat-а (вместо Session-файла на 175 КБ) | координатор / workflow |
| `lint_beat.py` | «Пол» качества beat-а: объём, запреты, повторы, формулы, фигуры, обращение | перед bf-critic |
| `assemble_chapter.py` | Сборка главы из принятых beat-ов, фактический подсчёт слов | после writer-loop |
| `init_book.py`, `backup.py`, `rollback.py` | Создание книги, бэкап, откат | автор / координатор |

Проверено на «Картах на стол», глава 1 (2026-10-01): фактический объём главы 4 603 слова
при заявленных моделью 6 145 — самоотчёт о длине beat-ов был завышен на 30–45 %.
