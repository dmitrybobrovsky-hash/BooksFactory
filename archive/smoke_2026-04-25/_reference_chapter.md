# Reference Chapter — SmokeTest

## Что измеряет smoke-test

Целостность контрактов между ролями. Не литературное качество. Не глубину голоса. Только pipeline-integrity: каждый артефакт по контракту приходит, каждый артефакт по контракту уходит.

## Почему так

Реальная литературная фабрика проверяется в финале на двух уровнях. Первый уровень — текст. Второй уровень — труба, по которой текст идёт. Если труба дырявая, идеальный текст разорвётся в местах склейки. Smoke-test проверяет вторую плоскость.

## Конкретно

Researcher собирает материал. Material-author структурирует его в beat sheets. Planner строит beat-план в JSON. Compiler склеивает Session_compiled.md по шаблону. Coordinator читает статус главы и определяет следующий шаг. Writer-loop (Ф8 — пока mock) превращает Session-файл в прозу beat'ами. Editor проверяет собранную главу. Humanizer стирает ИИ-отпечатки. Translator переводит.

Каждое звено имеет вход-контракт и выход-контракт. Каждое нарушение возвращается на предыдущую роль. Текущая роль не «чинит за соседа» — это нарушает изоляцию.
