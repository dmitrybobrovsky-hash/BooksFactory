# Система самопроверки Писателя

## Уровень 1 — Секционный Gate (после каждой секции)

Выполнять строго после каждой секции, до перехода к следующей.

### Тест 1 — Failure modes

Проверить текущую секцию по доминантной угрозе части книги.

Доминантная угроза берётся из:
1. `tonal_compass.md` книги (если там прописано)
2. `method/PATTERNS_OF_FAILURE.md` — кросс-книжный каталог
3. T2 Session-файла — специфические запреты этой главы

**Действие при обнаружении летального нарушения**: СТОП. Исправить до перехода к следующей секции.

### Тест 2 — Микрорежим

Вопрос: **каждый абзац выдержан в микрорежиме, назначенном в MATERIAL?**

Типичные конфликты:
- Саркастический панчлайн внутри секции «тихой горечи» → удалить или смягчить
- Тёплая интонация внутри «холодной клинической фиксации» → переписать
- Морализаторство внутри «горькой иронии» → удалить

Если микрорежим не прописан в MATERIAL → читать tonal_compass.md книги.

### Тест 3 — Объём

Подсчитать слова. Сравнить с таргетом секции из MATERIAL.

| Ситуация | Действие |
|---------|---------|
| В пределах ±10% | OK |
| Ниже таргета | Расширить через глубину: новые тезисы, парадоксы, детали |
| Выше таргета > 20% | Проверить на раздувание: `architecture/writing_control.md` |

**Запрещено**: расширение через переформулировку уже сказанного.

### Тест 4 — Абсолюты

Grep мысленно: «никогда», «всегда», «все», «ноль», «ни один», «каждый».

**Исключение**: эти слова внутри ритмических фигур, арен, декомпрессий — не трогать.

**Действие**: аналитический тезис с абсолютом → смягчить («в большинстве случаев», «как правило», «чаще всего») или добавить обоснование исключения.

### Тест 5 — Лексическое разнообразие

Специфическое/образное слово появилось 3+ раза в тексте к этому моменту?

Подробности ротации: `references/writing_principles.md` — раздел LP.

**Правило**: для каждого лишнего вхождения — своё слово по локальному контексту. Не одна замена для всех — это повтор под другим именем.

### Тест 6 — Счётчик сигнатурной фигуры

Посчитать «не потому что X — а потому что Y» / «nicht weil X — sondern weil Y» / «not because X — but because Y» в секции.

Нарастающий счётчик по главе. Лимит из T5 Session-файла (BooksFactory default: ≤ 8 на главу).

При превышении: оставить ударные (где создаётся парадокс), проходные — переписать: убрать зачин, начать с сути.

### Тест 7 — Обращение к читателю

Найти все обращения к читателю в секции.

| Запрещено | Заменить на |
|-----------|-----------|
| «вы» / «Вы» | «ты» |
| «Sie» (обращение) | «du» |
| «one» / «the reader» | «you» |
| «мы» (ложная солидарность) | «ты» или конкретный субъект |

## Уровень 2 — Мастер-чеклист (после всей главы)

Выполнять после написания всех секций, перед передачей Редактору.

### Порядок проходов (не менять)

#### Проход 1: Летальные нарушения

Источник: T2 Session-файла + tonal_compass.md книги.

Летальные нарушения специфичны для каждой книги. Примеры:
- ОНМ: демонизация (Q12), мизогиния (Q9), виктимблейминг (Q11)
- MdP: «Sie» в обращении, «Und jetzt dein Büro.» повтор
- Любая книга: нарушение обращения «ты/du/you»

**Действие**: найдено → СТОП, исправить до продолжения следующего прохода.

#### Проход 2: Структурные

- Beat sheet выполнен? Все beats присутствуют?
- Арены отработаны (если требует tonal_compass.md)?
- Физиологическая деталь есть (если требует тональная карта)?
- Открытие главы: сцена / парадокс / провокация — не абстрактное введение?
- Закрытие главы: удар или мост — не резюме?

#### Проход 3: Стилистика

- Тон соответствует tonal_compass.md по всем секциям?
- Микрорежимы выдержаны в каждой секции?
- Ритм разнообразен? Нет 5+ абзацев одинаковой длины подряд?
- Метафора не повторена из предыдущей главы?
- Восклицательные знаки в лимите (из тональной карты)?

#### Проход 4: Провокация

- Парадокс присутствует (хотя бы один на главу)?
- Горькая усмешка уникальна — не повторена из другой главы?
- Сигнатурная фигура в лимите (T5)?
- Closing главы уникален по всей книге?
- Провокация бьёт по механизму/системе, не по читателю?

#### Проход 5: Лингвистика

- Деепричастные обороты: подлежащее деепричастия = подлежащее главного предложения?
- Цепочки местоимений «он/она» — при двусмысленности повторить существительное?
- Предложения > 40 слов — каждое проверить трижды?
- Обращение «ты/du/you» во всей главе — без исключений?

## Самопроверка исправлений

После каждого исправленного фрагмента:
1. Не внёс ли я новый failure mode, исправляя старый?
2. Не сломал ли я микрорежим секции?
3. Не нарушил ли обращение к читателю?
4. Не добавил ли абсолют вместо убранного?
