# Repurpose to Reels — Создание скриптов Reels

## Процедура

1. Прочитай `CLAUDE.md` (аудитория и тон)
2. Прочитай `tonal_compass.md книги (или stil_und_ton_XX.md)` (голос, антипаттерны)
3. Прочитай исходный материал (`$ARGUMENTS`)
4. Извлеки 3–5 самых цепляющих идей

Для каждой идеи создай Reel по шаблону `tpl-reels-script.md`:

```
HOOK [0–3 сек]: фраза, останавливающая скролл
  Формулы: «Твой начальник — психопат, если...»
           «90% руководителей делают эту ошибку»
           Вопрос с неожиданным углом
  → предложи 2 варианта хука

VALUE [3–25 сек]: ОДНА конкретная мысль. Не три. Одна.
  Разговорный язык, короткие фразы, ноль канцелярита

CTA [25–30 сек]: подписка / сохранение / ссылка на книгу
```

## Правила голоса Reels

- Максимальный sharp — формат не терпит воды
- Никаких AI-шаблонов («важно отметить», «давайте рассмотрим»)
- Обращение: «ты» (RU) / «du» (DE)
- Одна мысль — один Reel

## Результат

3–5 файлов в `Content/Reels/scripts/` с `source` в frontmatter — ссылкой на оригинал.
