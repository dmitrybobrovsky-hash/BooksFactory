# Synthesize Ideas — Синтез идей из Inbox

## Процедура

1. Прочитай все файлы в `Inbox/`
2. Для каждой идеи:
   - Определи, к какому проекту/теме относится
   - Проверь: есть ли уже похожая заметка в vault (grep по ключевым словам)
   - Если да → дополни существующую
   - Если нет → создай атомарную заметку по шаблону `tpl-atomic-note.md`
3. Добавь wikilinks к связанным заметкам
4. Обнови соответствующие MOC
5. Пометь обработанные идеи в Inbox как обработанные (или перемести)

## Формат атомарной заметки

Шаблон: `Resources/Templates/tpl-atomic-note.md`

- Одна идея, своими словами, 1–3 абзаца
- `source` в frontmatter
- Связи через `[[wikilinks]]`

## Результат

Чистый Inbox + новые/обновлённые заметки + обновлённые MOC
