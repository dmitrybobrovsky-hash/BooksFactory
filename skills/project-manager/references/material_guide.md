# MATERIAL Guide — Формат и примеры

## Что такое MATERIAL

MATERIAL — препродакшн-документ главы. Это контракт PM с Писателем о том, что внутри каждой секции. Писатель читает MATERIAL вместо того, чтобы импровизировать структуру.

Хороший MATERIAL = Писатель не задаёт вопросов в процессе.

---

## Frontmatter

```yaml
---
глава: NN
название: "[Название главы]"
целевой_объём: XXXX слов
язык: ru|de|en
книга: "[Название книги]"
создан: YYYY-MM-DD
статус: material-draft
---
```

## Структура секции — полный формат

Каждая секция в MATERIAL содержит:

```markdown
### Секция N: [Название]

- **Целевой объём**: XXX слов
- **Микрорежим**: [горькая ирония | тихая горечь | холодное восхищение | ледяная клиническая фиксация | другой из tonal_compass.md]
- **Механизм**: [что именно исследуется — точная формулировка]
- **Провокация**: [острая формулировка, которая должна ударить читателя]

**Beat sheet**:
1. [Название beat] — XXX слов — [задача: что делает beat, не тема]
2. [Название beat] — XXX слов — [задача]
3. [Название beat] — XXX слов — [задача]
4. [Название beat] — XXX слов — [задача]
5. [Название beat] — XXX слов — [задача]

**Ключевой образ** (опционально): [метафора или физиологическая деталь — если книга использует такие]
```

### Разница между темой и задачей beat

| Плохо (тема) | Хорошо (задача) |
|-------------|-----------------|
| «Описать механизм» | «Назвать механизм + показать где он живёт в теле» |
| «Рассмотреть контраргумент» | «Признать долю правды в возражении + разрушить его через конкретный пример» |
| «Закрыть секцию» | «Горькая усмешка — один удар, без резюме» |

### Количество beats

- Стандарт: 5–7 beats на секцию
- Меньше 5 → секция скорее всего слишком абстрактная
- Больше 7 → возможно, стоит разбить на две секции

## Арены (если предусмотрены tonal_compass.md)

Арена — конкретная сцена, физически разворачивающая механизм.

```markdown
**Арены**:
- [🔴/🟡/🟢] [код механизма] → [описание момента в 1-2 предложениях]
  Декомпрессия: [Форма 1: тишина | Форма 2: констатация | Форма 3: деталь-объект]
```

Цветовые коды интенсивности:
- 🔴 высокая — острое телесное переживание
- 🟡 средняя — узнаваемая ситуация
- 🟢 низкая — фоновый момент

---

## Блок «Откуда это берётся» (если предусмотрен книгой)

Специфика ОНМ — секция-вставка 500–800 слов о генезисе паттерна.

Если книга использует подобный блок, MATERIAL должен содержать:
```markdown
**Блок «Откуда это берётся»** (~600 слов):
- Откуда паттерн берётся (происхождение, не оправдание)
- Микрорежим: ледяная клиническая фиксация
- НЕ содержит: сочувствие, оправдание, морализаторство
```

## Источники

```markdown
## Источники

| Автор | Название | Год | Фокус именно для этой главы |
|-------|----------|-----|------------------------------|
| [Фамилия] | [Название] | [год] | [конкретно что из этого источника нужно — не «вообще по теме»] |
```

**Правило**: поле «Фокус» — обязательное и уникальное.

Плохо: «Про нарциссизм» (одинаково для трёх глав)  
Хорошо: «Механизм проекции как защита от тревоги — конкретно раздел 4.2»

## Открытые вопросы для Писателя

```markdown
## Открытые вопросы для Писателя
- [ ] [Конкретный вопрос, требующий решения в процессе написания]
- [ ] [Например: «Нужна ли вторая арена в секции 3 или достаточно одной?»]
```

НЕ писать риторических вопросов («Как лучше раскрыть тему?»).

## Пример beat sheet из практики ОНМ

Реальная структура секции (обобщённая):

```
### Секция 1: Механизм молчания (~1800 слов)

- **Микрорежим**: холодное восхищение
- **Механизм**: молчание как регулятор тревоги, а не как осознанное оружие
- **Провокация**: «Она не молчит. Тревога молчит вместо неё.»

Beat sheet:
1. Открытие — 200 слов — назвать механизм через конкретный момент (не определение)
2. Анатомия — 400 слов — как именно работает: тело → поведение → эффект на партнёра
3. Парадокс — 300 слов — почему молчание «работает» для неё и разрушает его
4. Арена — 500 слов — конкретная сцена с декомпрессией
5. Удар — 150 слов — горькая усмешка, без резюме
```

## Чеклист PM перед передачей MATERIAL

- [ ] У каждой секции есть beat sheet (5+ beats)
- [ ] Каждый beat имеет задачу, не только тему
- [ ] Каждый источник имеет уникальный фокус для этой главы
- [ ] Перекрёстные ссылки проверены — нет повтора образа из соседней главы
- [ ] Открытые вопросы конкретные, не риторические
- [ ] Микрорежим каждой секции соответствует tonal_compass.md
