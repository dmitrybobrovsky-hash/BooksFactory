# Session Guide — Формат T1-T12

## Что такое Session

Session = правила одной сессии написания. Писатель читает Session перед первым словом и держит его открытым. Session не объясняет «что писать» (это MATERIAL) — Session объясняет «как писать именно эту главу».

В ОНМ MATERIAL и Session были объединены в один файл. В BooksFactory они разделены — но при желании можно объединить.

---

## Frontmatter

```yaml
---
глава: NN
название: "[Название]"
книга: "[Книга]"
материал: "[[MATERIAL_Glava_NN]]"
создан: YYYY-MM-DD
статус: session-ready
---
```

## T1: Метаданные

```markdown
## T1: Метаданные
- **Глава**: NN из [общего числа]
- **Целевой объём**: XXXX слов (минимум из tonal_compass.md)
- **Калибровочные главы**: [[Глава-эталон-1]], [[Глава-эталон-2]]
- **MATERIAL**: [[MATERIAL_Glava_NN]]
- **Тональная карта**: [[tonal_compass]]
- **Output filename**: NN_Glava_XX_[Название].md
```

Калибровочные главы — это эталон голоса, не содержания. Писатель читает их перед началом.

---

## T2: Специфические запреты этой главы

**Самый важный блок.** Здесь — только то, что специфично для ЭТОЙ главы. Не общие правила BooksFactory.

```markdown
## T2: Специфические запреты этой главы
- [Конкретный запрет 1: например, «не упоминать главу 3 — там тот же механизм»]
- [Конкретный запрет 2: например, «в секции 2 — ноль восклицательных знаков»]
- [Конкретный запрет 3: тема/образ/слово, которое нельзя использовать в этой главе]
```

Плохой T2: «Не нарушай голос серии» (это и так правило BooksFactory)
Хороший T2: «В секции 3 не использовать образ зеркала — он исчерпан в главе 7»

---

## T3: Разрешения / исключения

Что можно в этой конкретной главе, несмотря на общие запреты:

```markdown
## T3: Разрешения / исключения
- [Например: «В этой главе допустим второй восклицательный знак — уникальный контекст»]
- [Например: «Разрешена военная метафора в секции 4 — намеренная ирония»]
```

Если исключений нет — написать «нет».

---

## T4: Требования к аренам

```markdown
## T4: Требования к аренам
- Арена 1 (из MATERIAL, код): [тип декомпрессии]
- Арена 2: [тип декомпрессии]
- Запрет: не повторять форму декомпрессии из главы [N]
```

Если книга не использует арены — написать «не применимо».

---

## T5: Лимиты сигнатурных фигур

```markdown
## T5: Лимиты сигнатурных фигур
- «не потому что X — а потому что Y» (RU) / «nicht weil — sondern weil» (DE): не более [N] на главу
- «и вот что делает / и вот парадокс»: не более 1 суммарно
- «паттерн»: не более 2, ротация: механизм / реакция / привычка / рефлекс / схема
```

BooksFactory default: ≤ 8 для сигнатурной фигуры. Тональная карта может снизить лимит.

---

## T6: Метафорические территории

```markdown
## T6: Метафорические территории
- Разрешено: [медицина/хирургия, инженерия, юриспруденция — или из tonal_compass.md]
- Запрещено: [военные, религиозные, спортивные — или специфика книги]
- Приоритет: [первичная территория] → [вторичная]
```

---

## T7: Демонизация / нейтрализация (если применимо)

```markdown
## T7: [Специфический failure mode этой книги]
- [Например для ОНМ: «Агент → механизм. Рассчитала → тревога зафиксировала»]
- [Для MdP: «Описывать систему как механизм, не как злой умысел»]
```

Этот блок заполняется из `tonal_compass.md` книги.

## T8: Содержательные запреты

```markdown
## T8: Содержательные запреты
- [Например: «Не называть личные имена в кейсах — только роли»]
- [Например: «Не вставлять цитаты в текст — только блок источников в конце»]
- [Например: «Не ссылаться на другие книги серии»]
```

```markdown
## T9: Формула провокации
[механизм → парадокс → узнавание → горькая усмешка]
или специфическая для книги формула из tonal_compass.md
```

## T10: Лекторат-протокол

```markdown
## T10: Лекторат
После написания — пройти:
1. Деепричастные обороты: подлежащее деепричастия = подлежащее главного предложения
2. Цепочки местоимений: при двусмысленности повторить существительное
3. Предложения > 40 слов: проверить трижды каждое
4. [Языко-специфические пункты из tonal_compass.md]
```

---

## T11: Мастер-чеклист

```markdown
## T11: Мастер-чеклист
Приоритетный порядок (из references/checklist в skills/writer/):
1. Летальные нарушения (T7/T8)
2. Структурные (beat sheet, арены)
3. Стилистика (тон, микрорежимы, ритм)
4. Провокация (парадокс, сигнатурная фигура, closing)
5. Лингвистика (T10)
```

---

## T12: Протокол написания

```markdown
## T12: Протокол написания
- Писать секцию за секцией, не переходить к следующей без Gate pass
- Метод расширения через глубину: микроанатомия → парадокс → арена
- Запрещено: черновик → расширение
- Минимальный объём: [из tonal_compass.md книги]
```

---

## Как объединить MATERIAL и Session

Если удобнее вести один файл (как в ОНМ):

```
# MATERIAL + Session: Глава NN — Название

## Часть 1: MATERIAL
[Секции, beat sheets, источники]

## Часть 2: Session Protocol
[T1-T12]
```

Оба варианта правильны. Для новых книг — рекомендуется разделение (проще редактировать).

## Чеклист PM перед передачей Session

- [ ] T1 содержит output filename
- [ ] T2 содержит СПЕЦИФИЧЕСКИЕ запреты этой главы (не общие правила BooksFactory)
- [ ] T5 содержит числовой лимит сигнатурной фигуры
- [ ] T8 содержит запрет на источники-галлюцинации (явно написано)
- [ ] T12 содержит минимальный объём из tonal_compass.md
