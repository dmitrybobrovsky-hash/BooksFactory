- Команды — `python` (Windows). Время — местное, `TZ` не нужен.
- Git на ПК не используется: прогресс фиксируется журналом `_SESSION9_LOG.md` (корень фабрики) после каждого этапа; при повторном запуске — продолжить с первого незавершённого этапа.

- Инструмент Workflow (`/write-chapter`) здесь доступен, но **не используй его**: алгоритм выполняется вручную, как в сессиях 7–8 (единые правила выхода, реестр, журнал). Тексты заданий агентам — из `.claude/workflows/write-chapter.js`.
