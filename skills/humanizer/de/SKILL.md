# DeAI Writing DE — Удаление AI-паттернов из немецкого текста

## Назначение

Возвращать немецкому тексту голос автора — убирать признаки машинной генерации, не переписывать содержание. Не «гуманизация» ради гуманизации — а восстановление голоса «Intelligenter Mistkerl» («Интеллигентный сукин сын» в немецком эквиваленте).

---

## Позиция в производственной цепочке BooksFactory

```
PM → Писатель → Редактор → Гуманизатор
                                ▲
                                └── ты здесь (DE-модуль)
```

---

## Предусловия (проверить ДО запуска)

1. Глава имеет статус `clean` (прошла Редактора, правки применены)
2. Смысловая структура зафиксирована — Гуманизатор не перестраивает аргументацию
3. Файл `tonal_compass.md` книги прочитан — карта книги перекрывает все дефолты этого скилла
4. Для MdP: прочитан `MDP_ANALYSIS_REPORT.md` — там зафиксированы специфические проблемы

Если предусловие не выполнено — **вернуть артефакт на предыдущую роль**.

## Серийные инварианты (нельзя изменять ни при каких условиях)

| Правило | Формулировка |
|---------|-------------|
| Обращение к читателю | Только «du». Никогда «Sie», «man», «der Leser», «wir» |
| Сигнатурная фигура | «nicht weil X — sondern weil Y» — не трогать, только считать |
| Голос серии | Экспертный + острый. Не академический, не нейтральный, не коучинговый |
| Провокация | Субъект провокации — система/механизм, не читатель |

## Режимы работы

### Режим 1: AUDIT (detect)

Триггеры: «prüfe», «finde Marker», «audit», «flag only», «zeig die Probleme».

Формат ответа:

```
## AI-Muster-Audit: [Kapitel]

### Gefundene Marker

| # | Typ | Zitat | Problem | Level |
|---|-----|-------|---------|-------|
| 1 | Lexik T1 | «Es ist wichtig zu beachten, dass...» | Standard-KI-Marker | 🔴 |
| 2 | Struktur | Drei Absätze gleicher Länge | Monotoner Rhythmus | 🟡 |

### Bewertung
- Marker gesamt: N
- Kritisch (🔴): N
- Hinweis (🟡): N
- Optional (🟢): N

### Empfehlungen
[Конкретные шаги]
```

### Режим 2: REWRITE (по умолчанию)

Триггеры: «schreib um», «bereinige», «humanisiere», «entferne KI-Muster», «mach lebendig» — или любой запрос без указания режима.

**Процедура (строго по шагам):**

**Проход 1 — диагностика.**  
Прочитать текст целиком. Составить внутренний список всех найденных маркеров (пользователю не показывать). Сверить с `lexicon_de.md` и `patterns_de.md`.

**Проход 2 — переписывание.**  
Устранить все найденные маркеры. Правила:
- Сохранять фактическое содержание без потерь
- Не добавлять информацию, которой не было в оригинале
- Менять структуру предложений, не только слова
- Варьировать длину: короткое (3–7 Wörter), среднее, длинное
- Допускать неполные предложения, если уместно стилистически
- Не выравнивать абзацы по длине
- «du» — всегда, «Sie» — никогда

**Проход 3 — самопроверка.**  
Перечитать переписанный текст. Проверить:
- Не появились ли новые AI-маркеры?
- Не нарушен ли инвариант «du»?
- Не введена ли «Sie» форма случайно?
- Не сломан ли микрорежим секции?
- Не реинтродуцированы ли failure modes Редактора?

Если нашёл — исправить самостоятельно, не возвращать Редактору.

**Вывод пользователю:**

```
## Umgeschriebener Text

[текст]

## Was geändert wurde

| War | Wurde | Grund |
|-----|-------|-------|
| «Es ist wichtig zu beachten» | [умгеформулировано] | Tier-1-Marker |
| 3 gleich lange Absätze | Absätze 2/5/3 Zeilen | Monotoner Rhythmus |

## Selbstprüfung
N Marker nach Umschreiben gefunden → behoben / nicht gefunden.
```

## Система уровней маркеров

- **Tier 1 (🔴)** — Всегда флаг. Однозначный AI-признак. Заменять без обсуждения.
- **Tier 2 (🟡)** — Флаг при кластеризации. Одно вхождение допустимо, два и более в 500 словах — маркер.
- **Tier 3 (🟢)** — Флаг при высокой плотности. Нормально в малых дозах; флаг при > 3 на 1000 слов.

---

## Принципы переписывания (немецкий)

1. **Konkret statt abstrakt.** «Spielt eine wichtige Rolle» → назвать, что именно делает.
2. **Aktion statt Zustand.** «Ist die Grundlage von» → перестроить в действие.
3. **Mensch als Subjekt.** Неодушевлённые предметы не «betonen», «zeigen», «verdeutlichen» — это делают люди или данные.
4. **Rhythmische Vielfalt.** Чередовать короткое и длинное. Монотонный ритм — главный структурный AI-маркер.
5. **Nicht sterilisieren.** Допускать разговорные вкрапления — авторский текст не бывает идеально вычищенным.
6. **Kein Klischee durch Klischee ersetzen.** Убрал «Es ist wichtig» — не ставить вместо него «Es sei darauf hingewiesen». Перестроить предложение целиком.
7. **Schachtelsätze — с умом.** Немецкий допускает длинные предложения. Резать только те, что раздуты без смысла — не механически.

## Специфика MdP (Книга 1 серии)

| Проблема | Источник | Контроль |
|---------|---------|---------|
| «nicht weil X — sondern weil Y» ≤ 8 на главу | MDP_ANALYSIS_REPORT | Считать в Проходе 1, НЕ удалять |
| «Und jetzt dein Büro.» — уникальная closing-фраза | ANALYSIS_REPORT | Grep по всей книге, не допускать повтора |
| 19 дублированных аннотаций источников | MDP_ANALYSIS_REPORT | Не задача Гуманизатора, но зафиксировано |

## Самопроверка на реинтродукцию

Минимальный чек-лист после Прохода 3:

- [ ] Не появилось ли демонизирующих формулировок?
- [ ] Не нарушен ли инвариант «du» (не появилось «Sie» / «man» в обращении)?
- [ ] Не сломан ли микрорежим секции (тёплая нота внутри холодного регистра)?
- [ ] Не добавил ли абсолютных утверждений («niemals», «immer», «alle»)?
- [ ] Не введён ли коучинговый тон («Versuchen Sie», «Beachten Sie»)?
