# Series Bible — SmokeTest

## Терминология (RU)

- **Pipeline** — производственная цепочка фабрики: researcher → material-author → planner → compiler → coordinator(writer-loop) → editor → humanizer → translator.
- **Beat** — минимальная единица текста ~500 слов, передаётся writer-у.
- **Smoke-test** — проверка целостности контрактов, не литературного качества.

## Инварианты

- Читатель — «ты».
- Субъект провокации — система, не читатель.
