# Outline Book — Планирование структуры книги

## Процедура

### Контекст (прочитай перед работой)
1. `CLAUDE.md` — профиль автора, аудитория
2. `architecture/shared_vocabulary.md` — термины
3. Серийный канон (если книга часть серии, путь в брифе) — существующие книги, перекрёстные темы
4. `$ARGUMENTS` — тема, рабочее название, язык книги

### Шаги

1. **Предложи 3 варианта структуры** — разные логики повествования:
   - Вариант А: от симптома к механизму к выходу
   - Вариант Б: от кейса к теории к практике
   - Вариант В: [специфический для темы]
   
   Для каждого: количество частей/глав, логика прогрессии, плюсы и минусы.

2. **После выбора варианта** — создай `_outline.md` по шаблону `tpl-book-outline.md`:
   - Для каждой главы: название, ключевая идея (1 предложение), 3–5 подтем, примерный объём
   - Перекрёстные ссылки на главы других книг серии, где темы пересекаются
   - Пометить главы, требующие внешнего исследования

3. **Создай MOC** для книги в `MOCs/`

## Что НЕ делать

- Не писать главы — только структуру
- Не добавлять источники — это задача PM при создании MATERIAL
- Не копировать структуру предыдущей книги механически

## Результат

`_outline.md` в папке проекта книги + `MOCs/moc-[название].md`
