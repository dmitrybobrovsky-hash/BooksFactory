# BooksFactory — Конституция

BooksFactory — универсальная литературная фабрика. Режимы работы:

1. **Режим A — новая книга с нуля.** Полный пайплайн: исследование → MATERIAL → beat-план → writer-loop → редактура → гуманизация → финал.
2. **Режим B — продолжение начатой книги.** ⚠ Не реализован (см. `AUDIT_2026-10-01.md`). Подхват = заполненный и утверждённый слой A + запись в состоянии книги.

Работает с любой книгой, независимо от языка и темы. Специализации живут в файлах книги (`stil_und_ton_<CODE>.md`, `verbot_liste_<CODE>.md` и др.), а не в агентах фабрики.

## Производственная цепочка

```
bf-researcher → bf-material-author → bf-planner → bf-compiler → bf-coordinator (writer-loop) → bf-editor → bf-humanizer
```

Внутри `bf-coordinator` крутится цикл `bf-writer ↔ bf-critic` (max 3 итерации на beat; critic вызывается как изолированный subagent). Контракт цикла — `architecture/_TZ_WRITER_BEAT_BY_BEAT.md` §5.

Роли работают последовательно. Артефакт, не прошедший контракт, возвращается назад, а не исправляется текущей ролью.

## Статусы главы

```
(нет файла) → outline-ready → material-draft → draft → review → clean → humanized → final
```

Перевод — вне BooksFactory (TranslationFactory). Подстатусы writer-loop внутри `draft` (`compiled`, `beat-N-draft`, `beat-N-accepted`) — см. `.claude/memory/production_state.md`.

## Правила, которые нельзя нарушать

0. **Изоляция рабочей директории.** Работай ТОЛЬКО в директории, которую указал автор в текущем промпте. Не читай другие проекты, `archive/` и `_testing/` без явного указания. Путь к проекту — из `book_config.json` или из промпта автора.
1. **Честность источников.** Выдумывать источники запрещено. Вставлять нерелевантные источники или интернет-ссылки ради объёма запрещено. В раздел «Для дополнительного изучения» попадают только книги. Формат (per-chapter / unified) задаёт автор. Ссылки внутри глав на библиографию не делаются.
2. **Обращение к читателю** — «ты» (RU) / «du» (DE) / «you» (EN). Никогда «вы» / «Sie».
3. **Субъект провокации** — система/механизм, не читатель.
4. **Редактор не переписывает** — только указывает. Edit-инструмент ему запрещён.
5. **Тональная карта книги побеждает дефолты фабрики.** Иерархия голоса (книга > серия > фабрика) — `architecture/shared_vocabulary.md` §4.1.
6. **Лимиты повторов.** «Паттерн» — максимум 2 раза на главу. Сигнатурная фигура — максимум 8.
7. **Оперативный журнал сессии.** Перед значимым шагом — обновить `_SESSION_STATE.md` в директории книги (`status: in_progress`), после — снова (`status: completed`, `next: ...`). Формат — `BOOKSFACTORY_AI.md` §11.
8. **Изоляция фабрики от проекта.** Файлы фабрики (`.claude/agents/`, `.claude/skills/`, `skills/`, `architecture/`, `templates/`) не содержат имён книг, кодов книг, путей к проектам. Проектный контекст — только через `book_config.json`. Проверка: `python tools/validate_factory.py` (проверяет также фронтматтер агентов и скиллов).

```
├── _outbound/              ← рабочие директории книг
└── archive/                ← завершённое и устаревшее
```
