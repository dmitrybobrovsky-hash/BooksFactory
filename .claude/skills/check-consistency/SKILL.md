# Check Consistency — Проверка консистентности

## Процедура

1. Загрузи `серийном каноне (если есть)`, `тональной карте книги`, `architecture/shared_vocabulary.md`
2. Загрузи тональную карту книги (если есть)
3. Пройди по всем главам проекта (`$ARGUMENTS`)

### Что проверять

| Тип | Как проверять |
|-----|---------------|
| Единообразие терминов | grep по ключевым терминам из серийном каноне (если есть) — варианты написания |
| Обращение к читателю | grep «вы», «Вы», «Sie» (нарушение), «ты», «du» (норма) |
| Консистентность тона | Сравни с тональной карте книги — нет ли академического дрейфа, коучинга |
| Сигнатурные фигуры | Частота «nicht weil/не потому что» по главам |
| Форматирование | Заголовки, списки, выделения — единообразие |
| Перекрёстные ссылки | Упоминания других глав серии — консистентны? |

## Формат отчёта

`consistency-report.md` в папке проекта:

```markdown
# Отчёт консистентности — [Название книги]

## Терминология
| Проблема | Файл | Строка | Текущее | Правильное |

## Обращение к читателю
| Нарушение | Файл | Строка |

## Тон
| Нарушение | Файл | Секция |

## Сигнатурные фигуры
| Глава | Количество | Норма (≤8) |

## Итог
- Критических нарушений: N
- Замечаний: N
```
