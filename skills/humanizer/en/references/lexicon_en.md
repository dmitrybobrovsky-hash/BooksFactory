# Lexicon EN — English AI Markers

## Tier 1 — Always Flag (replace without discussion)

### High-frequency AI vocabulary

| Marker | Why problematic |
|--------|----------------|
| delve (into) | #1 most overused AI word |
| tapestry | Abstract decorative metaphor |
| vibrant | Empty intensifier |
| pivotal | Inflation marker |
| crucial | Overused significance marker |
| key (as adjective without specificity) | «key role», «key aspect» — meaningless |
| showcase | AI promotional verb |
| underscore | AI analytical verb |
| highlight (as AI self-commentary) | «this highlights that...» |
| foster | AI abstraction verb |
| garner | Rarely used by humans outside formal writing |
| interplay | Abstract relations marker |
| landscape | «the landscape of X» — AI spatial metaphor |
| testament (to) | «is a testament to» — AI significance formula |
| intricate | Decorative complexity marker |

## Tier 2 — Flag When Clustered (≥ 2 in 500 words)

### Significance inflation

| Marker | Note |
|--------|------|
| stands as | 1 per chapter max |
| serves as | 1 per 500 words |
| marks (a shift/moment) | 1 per chapter |
| reflects broader | 1 per chapter |
| underscores its importance | Combine with underscore count |
| indelible mark | 1 per book |
| profound (impact/effect) | 1 per chapter |
| groundbreaking | 1 per chapter |

### Vague attribution

| Marker | Fix |
|--------|-----|
| Industry reports suggest | Name the report or remove |
| Observers have cited | Who? Name them |
| Experts argue | Which experts? |
| Some critics argue | Name or remove |
| Several sources indicate | Name or remove |

### Copula substitutes (overused)

| Marker | Fix |
|--------|-----|
| serves as (replacing «is») | Use «is» or restructure |
| stands as (replacing «is») | Use «is» or restructure |
| represents (replacing «is») | Often deletable |
| boasts | Remove or use active verb |
| features (as «has») | Use «has» or restructure |

## Tier 3 — Flag at High Density (> 3 per 1000 words)

| Marker | Norm |
|--------|------|
| actually | ≤ 2 per 1000 words |
| additionally | ≤ 2 per 1000 words |
| furthermore | ≤ 2 per 1000 words |
| moreover | ≤ 2 per 1000 words |
| nevertheless | ≤ 1 per 1000 words |
| nonetheless | ≤ 1 per 1000 words |
| it is worth noting | ≤ 1 per chapter (T1 if repeated) |
| it should be noted | ≤ 1 per chapter |
| it is important to note | T1 always |
| in order to | ≤ 3 per 1000 words |
| due to the fact that | ≤ 1 (prefer «because») |
| at this point in time | ≤ 0 (use «now») |

## Hedging / Filler (context-dependent)

| Marker | When problematic |
|--------|-----------------|
| could potentially | Redundant: «could» already = potential |
| might have some | Vague softening |
| the ability to | Usually deletable: «can» |
| in a way that | Often restructurable |
| somewhat | Overuse = loss of authorial position |
| rather | AI hedging when overused |

## Series Invariants (not markers — rules)

| Rule | Action |
|------|--------|
| «you» only for reader address | Replace «one», «the reader», «we» (false solidarity) |
| «not because X — but because Y» | Count only, never remove |
| No coaching register | Remove «you might want to», «consider», «it would help to» |
