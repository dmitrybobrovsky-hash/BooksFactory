# Edit Chapter — Редактура главы

## Режимы

Уточни у автора (или выбери по контексту):

| Режим | Что проверяет | Когда |
|-------|--------------|-------|
| `structural` | Логика, порядок секций, пробелы в аргументации | Первый черновик |
| `style` | Голос, ритм, читабельность, failure modes | После структурной правки |
| `line-edit` | Конкретные правки на уровне предложений | После стилевой |
| `final` | Опечатки, пунктуация, форматирование, терминология | Финальная вычитка |

## Процедура (все режимы)

1. Прочитай `architecture/shared_vocabulary.md`
3. Если книга в серии — прочитай серийный канон (терминология серии, путь в брифе/anweisungen)
4. Прочитай тональную карту книги (`tonal_compass.md`)
5. Прочитай главу целиком
6. Создай отчёт по формату из `.claude/skills/editor/SKILL.md`

## Принцип

Твоя работа — **усилить текст автора, не заменить его своим**.  
Правки в формате: БЫЛО → СТАЛО + причина.  
Никогда не переписывай молча.

## Полный скилл Редактора

`.claude/skills/editor/SKILL.md` — мастер-чеклист, все FM-коды, формат отчёта.
