# Connect to Existing — Связи заметки с vault

## Процедура

1. Прочитай заметку (`$ARGUMENTS`) — извлеки ключевые концепции
2. Поиск в vault:
   - Заметки с похожими тегами
   - Заметки с пересекающимися темами (grep по концепциям)
   - Главы книг, где упоминается эта тема
   - Модули курсов со связанным материалом
3. Предложи wikilinks для добавления в заметку
4. Предложи, в какие MOC добавить ссылку
5. Покажи «граф связей» текстом: что с чем связано

## Формат вывода

```
## Предложенные связи для [[Название заметки]]

### Wikilinks для добавления
- [[Заметка 1]] — причина связи
- [[Глава 3, Книга 1]] — пересечение темы X

### MOC для обновления
- [[moc-org-psych]] — добавить ссылку в раздел Y

### Граф связей
Заметка ↔ [[A]] (через тему X)
Заметка ↔ [[B]] (через концепцию Y)
```

## Результат

Список предложенных wikilinks + обновлённые заметки (после подтверждения)
