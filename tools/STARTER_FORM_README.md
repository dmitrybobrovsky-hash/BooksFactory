# BooksFactory Starter Form

## Как пользоваться

1. Открой `starter_form.html` двойным кликом в браузере
2. Заполни обязательные поля (название, тон, аудитория, идеи)
3. При необходимости раскрой «Расширенные настройки»
4. Нажми «Скачать JSON»
5. Кинь скачанный `book_config.json` в Claude и скажи «инициализируй проект»

Claude запустит `python tools/init_book.py book_config.json` и создаст директорию проекта.

## Файлы

- `starter_form.html` — форма, открывается в браузере
- `init_book.py` — скрипт инициализации (вызывается Claude, не автором)
