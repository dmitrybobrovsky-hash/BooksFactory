# Repurpose to Lecture — Сценарий видео-лекции

## Процедура

1. Прочитай `CLAUDE.md`, `tonal_compass.md книги (или stil_und_ton_XX.md)`
2. Загрузи исходную главу/модуль (`$ARGUMENTS`)
3. Определи 3–5 ключевых блоков
4. Создай скрипт по шаблону `tpl-video-script.md`

## Структура сценария

```
ОТКРЫТИЕ [0:00–0:30]
  Хук — вопрос/провокация/факт за 5 секунд
  НЕ: «Здравствуйте, сегодня мы поговорим о...»

БЛОК 1–N [хронометраж]
  Тезис → объяснение → пример → вывод
  Визуальные подсказки: что показать на экране
  Пометки для монтажа

ЗАКРЫТИЕ
  Резюме (3 пункта максимум) + CTA
```

## Правила

- Тон: как объясняешь умному другу, не как читаешь доклад
- Помечай хронометраж каждого блока
- Добавляй заметки для монтажа: B-roll, вставки, паузы
- `source` в frontmatter — ссылка на оригинал
